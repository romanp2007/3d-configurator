### 2. Frontend (client/)

**Стек:** Vite + React 18 + TypeScript 5 + TailwindCSS

**Созданные файлы:**

- `client/package.json` - зависимости и скрипты
- `client/vite.config.ts` - конфигурация Vite с proxy `/api → http://localhost:3001`
- `client/tsconfig.json` - TypeScript конфигурация с path aliases (`@/`, `@shared/`)
- `client/tsconfig.node.json` - конфигурация для Vite
- `client/tailwind.config.ts` - конфигурация TailwindCSS с кастомными темами
- `client/postcss.config.js` - PostCSS с Tailwind и Autoprefixer
- `client/index.html` - точка входа HTML
- `client/src/main.tsx` - точка входа React
- `client/src/App.tsx` - главный компонент с проверкой подключения к API
- `client/src/styles/globals.css` - глобальные стили с Tailwind директивами
- `client/src/vite-env.d.ts` - типы для Vite

**Особенности:**

- Настроен proxy для проксирования `/api` запросов на backend
- Path aliases для удобного импорта (`@/components`, `@shared/types`)
- Базовый UI с проверкой статуса API через `/api/health`

### 3. Backend (server/)

**Стек:** Node.js 20 + Express + TypeScript + Prisma

**Созданные файлы:**

- `server/package.json` - зависимости и скрипты
- `server/tsconfig.json` - TypeScript конфигурация для Node.js
- `server/src/index.ts` - Express сервер с базовыми middleware
- `server/prisma/schema.prisma` - схема БД с моделью Scene
- `server/prisma/migrations/.gitkeep` - папка для миграций

**Реализованный функционал:**

- ✅ CORS middleware с настройкой origins из `.env`
- ✅ JSON body parser
- ✅ Health check endpoint: `GET /api/health`
- ✅ 404 обработчик для несуществующих маршрутов
- ✅ Глобальный обработчик ошибок
- ✅ Hot reload через `tsx watch`

**Prisma схема:**

```prisma
model Scene {
  id        String   @id @default(uuid())
  name      String
  thumbnail String?
  data      Json
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
```

### 4. Общие типы (shared/)

**Файлы:**

- `shared/package.json` - конфигурация пакета
- `shared/tsconfig.json` - TypeScript конфигурация
- `shared/types/scene.ts` - типы для работы со сценами
- `shared/types/index.ts` - экспорт всех типов

**Определенные типы:**

- `ObjectType` - типы 3D объектов (box, sphere, cylinder, cone, plane, torus, model)
- `MaterialData` - свойства материала объекта
- `SceneObjectData` - полное описание объекта сцены
- `CameraData` - позиция и таргет камеры
- `EnvironmentData` - настройки окружения (фон, ambient light)
- `SceneData` - полные данные сцены
- `SceneMetadata` - метаданные для списка сцен
- `Scene` - объединение метаданных и данных сцены

## Инструкции для запуска

### 1. Запуск PostgreSQL

```bash
docker-compose up -d
```

### 2. Выполнение миграций

```bash
cd server
npx prisma migrate dev --name init
npx prisma generate
cd ..
```

### 3. Запуск dev серверов

```bash
# Запустить клиент и сервер одновременно
npm run dev

# Или отдельно:
npm run dev:client  # Frontend на http://localhost:5173
npm run dev:server  # Backend на http://localhost:3001
```

### 4. Проверка работы

- Frontend: http://localhost:5173
- Backend API: http://localhost:3001
- Health check: http://localhost:3001/api/health
