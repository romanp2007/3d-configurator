## 5. 3D-редактор сцен в браузере

**Что делаем:** Упрощённый редактор, в котором можно расставлять объекты на сцене, менять их свойства, сохранять и загружать сцены. Мини-аналог инспектора Unity в вебе.

**Стек:** React + TypeScript + Three.js + Zustand + Node.js + SQL (PostgreSQL) + Docker

**Features**

- Сложное взаимодействие UI и 3D-сцены (трансформ-гизмо, выделение объектов)
- Бэкенд для сохранения проектов (Node.js, SQL, Docker)

**Ключевые фичи:**

- Drag & drop объектов, gizmo для перемещения/вращения/масштаба
- Панель свойств объекта (React UI) (материал, позиция, свет)
- Сохранение/загрузка сцен через API
- Undo/redo система
- Панель настроек (React UI) синхронизирована с 3D-сценой
- Скриншот/экспорт результата
- Мобильная адаптация с touch-управлением
